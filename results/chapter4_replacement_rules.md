# Chapter 4 replacement rules

Use these rules when updating the Word thesis after the full pipeline has been run on the supplied CSVs.

1. Do not manually invent or round a metric before recording the raw output.
2. Keep the exact split and random seed: `test_size=0.20`, `random_state=42`, stratified for classification.
3. Report Accuracy, weighted Precision, weighted Recall, and weighted F1 for every classifier.
4. For binary targets, also report positive-class Precision, Recall and F1. For IBM HR this means `Attrition=Yes`.
5. Use the confusion matrix generated by the same run; never reconstruct it from rounded percentages.
6. For K-Means, report the full k=2..7 evaluation and select the maximum Silhouette Score.
7. For Green Innovation and Sustainable Performance, treat continuous outcomes as regression targets and report R², MAE and RMSE.
8. Any older Word number that cannot be reproduced by the current code/data combination must be replaced or explicitly marked as provisional.
9. Do not claim RBF SVM when the committed pipeline uses `LinearSVC`.
10. Do not claim an accuracy threshold was achieved unless the corresponding current run proves it.
