# Chapter 4 replacement rules

## Numeric authority

The authoritative numeric reference for the repository is the main thesis `آرین پوراسدedit(2).docx`. The curated Chapter 4 results must match the values reported in that thesis unless a later thesis revision explicitly supersedes them.

1. Treat the thesis as the numeric reference for dataset sizes, class counts, train/test counts, model metrics, regression metrics and K-Means results.
2. Do not silently replace thesis values with results from a different dataset version, random seed, preprocessing pipeline or hyperparameter configuration.
3. The four datasets remain independent and are never merged. The raw-record total is **75,756** and is not a single sample.
4. Classification datasets: IBM `Attrition`, Job Change `target`, Employee Promotion `is_promoted`.
5. GHRM regression target: `FEP`; base predictors are `GRS`, `GTD`, `GPA`, `GCM`; supplementary analysis adds `GEE`.
6. Classification models reported in the thesis are Random Forest, Decision Tree, LinearSVC and MLPClassifier. GHRM regression models are Random Forest Regressor, Decision Tree Regressor, LinearSVR and MLPRegressor.
7. Classification uses 80/20 train-test splitting and 3-fold cross-validation in the reported Chapter 4 implementation. The test set is used only for final evaluation.
8. K-Means evaluates `k=2...7` and selects the value independently for each dataset. Thesis reference selections are IBM=2, Job Change=3, Employee Promotion=5 and GHRM=2.
9. Classification metrics are Accuracy, positive-class Precision, Recall, F1-Score and Confusion Matrix. GHRM regression metrics are R², RMSE and MAE.
10. McNemar is used only for paired classification predictions on the same test set. Do not invent p-values where the thesis does not report an exact value.
11. If a fresh execution produces different numbers, preserve the thesis numbers in the curated reference file and document the execution discrepancy separately. Never overwrite the thesis reference silently.
12. The repository must not claim that a number was generated by the current pipeline unless that exact pipeline/data/configuration produced it.
