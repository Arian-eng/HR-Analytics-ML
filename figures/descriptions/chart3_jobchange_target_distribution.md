# chart3_jobchange_target_distribution

**Purpose:** visualizes class balance in the Job Change benchmark dataset.

**Interpretation:** the classes are imbalanced (approximately 75.07% versus 24.93%), so F1, recall and precision are more informative than accuracy alone.

**Source:** `aug_train.csv` analysis and `src/generate_chapter4_charts.py`.

**Limitation:** class frequency does not explain why job change occurs.
