# promotion_decision_tree

**Purpose:** documents the fitted Employee Promotion Decision Tree classifier.

**Structure:** depth 63 with 4,855 leaves.

**Performance:** Accuracy 0.8982, Precision 0.4113, Recall 0.4518, F1 0.4306.

**Interpretation:** the tree is highly complex and therefore has a clear overfitting/interpretability risk; this complexity is reported rather than hidden.

**Limitation:** it should not be presented as preferable simply because it exists in the candidate set.
