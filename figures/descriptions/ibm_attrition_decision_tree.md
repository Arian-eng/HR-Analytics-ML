# ibm_attrition_decision_tree

**Purpose:** exposes the fitted IBM Decision Tree classifier structure.

**Structure:** depth 6, 38 leaves.

**Performance:** held-out Accuracy 0.7483, Precision 0.3291, Recall 0.5532, F1 0.4127.

**Interpretation:** provides transparent decision rules but is not the best-F1 IBM model.

**Limitation:** the final fitted depth differs from some earlier thesis wording and should be defended using the committed executed pipeline.
