# Chapter 4 output specification

This document defines the reproducible outputs required for the thesis Chapter 4.

## Classification datasets

- IBM HR Attrition — target: `Attrition`
- Job Change — target: `target`
- Employee Performance — target: `KPIs_met_more_than_80`

For each dataset and model, report:

- Accuracy
- Weighted Precision
- Weighted Recall
- Weighted F1
- Cross-validation best weighted F1
- Best hyperparameters
- Confusion matrix

For IBM HR additionally report positive-class (`Attrition=Yes`) Recall and F1 because the target is imbalanced.

## Models

- Random Forest
- Decision Tree
- Linear SVM
- Neural Network (MLP)

## Clustering

Run standardized numeric-feature K-Means for k=2..7 (subject to sample size), and select the k with the highest Silhouette Score. Store inertia and Silhouette for every k.

## Green HRM regression datasets

The dedicated Green Innovation and Sustainable Performance datasets are analyzed as regression problems rather than forcing continuous outcomes into binary classes. Report R², MAE and feature importance where applicable.

## Reproducibility rule

Only values generated by the current committed code and supplied raw datasets should be used as final thesis results. Values copied from earlier drafts must be treated as provisional until reproduced.
