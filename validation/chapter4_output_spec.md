# Chapter 4 output specification

This specification matches the current four-dataset pipeline in `run_all.py`.

## Classification datasets

- IBM HR Attrition — target: `Attrition`
- Job Change — target: `target`
- Employee Promotion — target: `is_promoted`

For each dataset and model, report:

- held-out Accuracy
- positive-class Precision, Recall, and F1
- three-fold training CV best F1
- 95% non-parametric bootstrap intervals for held-out metrics
- best hyperparameters
- the held-out confusion matrix
- the saved label mapping used to encode the binary target

The four classifiers are Random Forest, Decision Tree, Linear SVM, and MLP. McNemar comparisons use the same held-out observations for Random Forest versus each other classifier.

## GHRM regression

The fourth dataset uses continuous `FEP` as the outcome. Report R², RMSE, and MAE with 95% bootstrap intervals for Random Forest Regressor, Decision Tree Regressor, LinearSVR, and MLPRegressor. Report the base predictors (`GRS`, `GTD`, `GPA`, `GCM`) separately from the supplementary `GEE+` variant, and report their paired bootstrap differences.

## Independent clustering

Run K-Means separately for every dataset with `k=2..7`. Exclude targets and identifiers from cluster formation, then report Inertia/SSE, Silhouette, Davies-Bouldin, and cluster sizes. For datasets larger than 5,000 rows, Silhouette uses a deterministic 5,000-row sample (`random_state=42`) to bound its quadratic distance calculation.

K-Means on standardized numeric plus one-hot categorical features is exploratory.
Do not treat Euclidean proximity in this mixed representation as a validated
substantive employee taxonomy.

## Reproducibility rule

Only values generated by the current code and the exact supplied raw datasets may be treated as final Chapter 4 results. Historical Employee Performance and Green Innovation/Sustainable Performance benchmarks belong to a superseded methodology and must not be mixed with this pipeline.

Persian presentation tables use Persian digits and the ASCII full stop (`.`) as
the decimal separator. Machine-readable CSV files retain ASCII digits.
